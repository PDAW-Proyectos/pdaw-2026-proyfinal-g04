# KCHIN - Gestor de caja comercial

> KCHIN está dirigida a pequeños y medianos comercios que necesitan simplificar la gestión diara de caja, centralizar sus ventas con un sistema POS, registrar sus movimientos y llevar un análisis de ellos junto con el arqueo y cierre de caja de forma rápida, segura y confiable.

Proyecto del equipo 4 para _7513 · Proyecto de Desarrollo de Aplicaciones Web_
(Tecnicatura Universitaria en Programación Web y Móvil — DCIC — UNS).

## Ficha del proyecto

| Aspecto                | Descripción                                               |
| ---------------------- | --------------------------------------------------------- |
| Problema               | App web para gestionar y controlar la caja de un comercio |
|------------------------|-----------------------------------------------------------|
| Usuarios               | Dueños de un local comercial y sus empleados              |
|------------------------|-----------------------------------------------------------|
| Funcionalidades núcleo | 1. Arqueo y cierre de caja                                |
|                        | 2. Realización y control de ventas                        |
|                        | 3. Control de stock y actualización de precios            |
|                        | mediante API dólar                                        |
|------------------------|-----------------------------------------------------------|
| Reglas de negocio      | 1. Solamente los usuarios con permisos pueden realizar    |
|                        |    el cierre de caja                                      |
|                        | 2. Unicamente el usuario administrador puede acceder al   |
|                        |    panel admin                                            |
|                        | 3. Solo el repositor o el administrador pueden gestionar  |
|                        |    el catálogo de stock                                   |
|------------------------|-----------------------------------------------------------|
| API externa            | Nombre, URL de la documentación y uso previsto            |
